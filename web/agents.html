Run a downloaded pack

  1. Extract the ZIP and open a terminal in the agent folder.
  2. Run python agent.py --demo to use synthetic sample data without credentials.
  3. Copy .env.example to .env, enter your provider key and model, and review config.json.
  4. Run python agent.py --run for a provider-generated draft. Add --overwrite only to replace existing outputs.

Live mode sends configured inputs to your chosen provider and incurs provider charges. Drafts require human review. These are bounded starter workflows, not autonomous tool-execution agents or security-certified products. Current checks cover the declared operations; they do not establish output accuracy or general safety.
