Run a downloaded pack

  1. Extract the ZIP and open a terminal in the agent folder.
  2. Run python agent.py --demo to use synthetic sample data without credentials.
  3. Review config.json and the included README. Draft assistants use your provider key and model; browser workflows use reviewed targets and optional manual portal sign-in.
  4. For browser workflows, install requirements.txt and Chromium, then run python agent.py --run --approve-config. Follow the pack’s instructions for other modes.

Provider-based draft assistants send configured inputs to your selected provider and may incur charges. Browser workflows can visit approved sites, collect reports or capture screenshots; review permissions before live use. Document entries and research comparisons are drafts for review. These are bounded, code-driven workflows, not general desktop-control agents or security-certified products. Checks cover declared operations and do not establish output accuracy or complete safety.
