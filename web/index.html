Every finding identifies a rule and the action IDs behind it. Review the original trace alongside its configuration snapshot.

Run both versions on identical inputs. Compare task success, policy findings, invalid steps, recovery, reported cost and measured latency. Missing evidence stays unknown.

IMPROVEMENT WITH DEVELOPER REVIEW

Learn what to test next.

OpenCaliber uses version-comparison evidence to propose additional tests and improvements. Adaptive means improving the review loop—not silently rewriting policies or modifying deployed agents.

Compare the same cases

Give two application-owned agent callbacks isolated copies of the same inputs. Use explicit success assertions and retain the policy fingerprint.

Diagnose the difference

Inspect task regressions, the first invalid tool call, recovery and measurement gaps. A permitted tool call can still lead to an unsuccessful task.

Review the next experiment

Export proposed boundary tests, failure-path tests and improvements. Developers decide what to change, rerun and promote. Initial proposals are deterministic, not trained-model judgments.

CAPABILITIES AND LIMITS

Built to help you evaluate.
Not to promise perfect safety.

OpenCaliber evaluates declared action metadata with deterministic rules. Its tracking wrapper reports outcomes and can reject a proposed callback in enforce mode. It cannot observe unwrapped operations or undo execution.

What works today

  • Deterministic evaluation of normalized action traces.
  • Console UI, Python API, CLI and SQLite-backed history.
  • Task scope, resource and transfer checks.
  • Configurable limits and a labeled regression suite.
  • Tracking sends instrumented action metadata to your configured console; no external model inference.

What this preview does not do

  • Infer arbitrary intent with a trained LLM.
  • Authenticate supplied scope or approval statements.
  • Observe operations that have not been instrumented.
  • Execute containment or guarantee threat prevention.
  • Provide multi-user authentication or tenant isolation.

BEFORE YOUR FIRST RUN

Frequently asked questions

Does it work with Gemini, Claude, or other agents?

The evaluator is model-neutral because it accepts normalized traces. Map your custom tools to supported checks in the Connect agents page or SDK. Completed-response adapters for OpenAI Responses, Chat Completions and Anthropic Messages are included. Your application must call the adapter; there is no automatic interception.

What does a risk score mean?

It is the maximum triggered rule severity on a 0–100 scale. It is not a calibrated probability of harm. Review the triggered rules and evidence rather than treating the number as certainty.

Can I use it with a company’s sensitive traces?

The downloaded console binds to loopback and has no login. Hosted deployments protect a shared workspace with authentication and HTTPS, but have no per-user roles or tenant isolation. SDK evidence can be redacted before storage. Review the deployment and privacy documentation before using sensitive traces.

Does passing the test suite mean my agent is secure?

No. These are hand-authored synthetic contract checks for implemented rules. They are not an independent security benchmark, and they do not cover arbitrary attacks, model behavior or hidden history.

What does it cost?

The included deterministic engine requires only Python’s standard library and makes no paid API calls. There is no subscription or billing flow in this preview.
