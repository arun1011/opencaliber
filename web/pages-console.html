Run the OpenCaliber console

This public website hosts documentation and downloads. Evaluations run in your own Python environment; this site does not collect or evaluate your traces.

Download and start

Download console package

  1. Install Python 3.10 or newer.
  2. Extract the downloaded ZIP into a new folder.
  3. On Windows, double-click start-windows.cmd. Or open a terminal in the extracted folder and run:
python run.py

On macOS or Linux, use python3 run.py.

Open http://127.0.0.1:8787/console on the same computer. No provider key is needed for built-in examples.

Connect an existing Python agent

Keep the console running. From the extracted package folder, try this agent, which contains no OpenCaliber imports:

python -m opencaliber.connect --agent-id sqlite-demo -- examples/observe_agent/agent.py

For your own script, make the OpenCaliber package importable in its environment, then replace its startup command:

python -m opencaliber.connect --agent-id my-agent --version v1 -- my_agent.py
  1. Open Agents Dashboard and search for your agent ID.
  2. Select Inspect run or Detected problems to review calls, policy findings and suggested corrections.
  3. Open Monitoring coverage for missing evidence. Correct the agent, rerun and inspect the next run.

The launcher observes default SQLite, urllib and installed synchronous Requests/HTTPX clients. Async clients, files, custom SQLite factories and child processes are outside coverage. No SQL, rows, bodies, headers or URL paths are collected. Up to 200 actions are captured per invocation. Task success remains unknown.

Observation or pre-dispatch blocking

Launcher connections are labeled Observe · Python launcher. They evaluate calls after execution and never block them, regardless of platform mode. Restore the original startup command to remove monitoring.

For blocking, selected outputs, task-success assertions and multi-agent links, open Connect an Agent in your console and expand the advanced integration example. Library agents already use this explicit integration; run python agent.py --demo without the launcher. In Advanced settings, review platform boundaries before choosing Block violations. Wrapper enforcement needs a reachable evaluator; it does not undo effects or sandbox the callback.

Share a console inside your company

Deploy the Python service behind HTTPS on your internal domain. Set OPENCALIBER_PUBLIC_ORIGIN to that exact HTTPS origin, configure a secret OPENCALIBER_ADMIN_TOKEN and persistent storage. Open that domain's /console; sign in as admin using the token as password.

OPENCALIBER_ENDPOINT=https://opencaliber.internal.example
OPENCALIBER_TOKEN=your-private-workspace-token
OPENCALIBER_TRACKING_ID=my-agent-project

Set these variables on remote agents. Do not use opencaliber.net as your collector: this GitHub Pages website has no Python backend. Your internal DNS, TLS certificate and firewall must allow agents to reach your own service. Do not expose the loopback launcher to a network.

What the results mean

Violation identifies a triggered boundary; review marks uncertainty; clear means no implemented rule triggered. Scores are rule severity, not probabilities. Only instrumented operations are tracked. The evaluator cannot undo actions, infer all intent or provide a sandbox.

Online metadata is evaluated before history minimization. Do not put secrets in trace fields. Observation delivery failures queue minimized metadata; explicit wrapper enforcement requires a reachable evaluator. History stays in your environment. The hosted service protects one shared workspace, without per-user roles or tenant isolation.

Compare versions before promotion

Run python examples/connected_versions/run.py, then open Compare agent versions in your running console. Select two tracked cohorts and review matched cases, task success, policy findings, cost, latency and trajectories. No upload is required.

Develop and test checks

Detection capabilities guides you through defining, coding, testing and enabling a check. Optional coding models can draft code for your review. Regression tests saves captured runs as reusable policy tests. Advanced settings holds shared boundaries and mode. Start monitoring with defaults, then review permissions before relying on blocking.

Developer Guide covers all seven sidebar menus with examples and current screenshots. The package also includes docs/console-guide.md.

Missing endpoint or no activity?

Restart an older server after replacing the package, then refresh. Check the agent endpoint, token, certificate trust and connection mode. Launcher setup and coverage are in docs/python-launcher.md; explicit integration details are in docs/automatic-tracking.md inside the console package.
